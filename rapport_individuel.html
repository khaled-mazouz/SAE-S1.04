2. Six requêtes SQL au choix

1 CA total des fournisseurs de l'Union européenne

Objectif : Connaître le chiffre d'affaires généré par chaque fournisseur européen, dans une optique de stratégie écoresponsable.

SELECT
    Fournisseur.Societe AS Fournisseur,
    SUM(
        DetailCommande.Quantite
        * Produit.CoutAchat
        * Categorie.CoefMarge
        * (1 - DetailCommande.Remise / 100)
    ) AS CA_Total
FROM ((((Commande
    INNER JOIN DetailCommande ON Commande.[N° commande] = DetailCommande.[N° commande])
    INNER JOIN Produit ON DetailCommande.RefProduit = Produit.RefProd)
    INNER JOIN Categorie ON Produit.CodeCateg = Categorie.CodeCateg)
    INNER JOIN Fournisseur ON Produit.NoFour = Fournisseur.NoFour)
WHERE Fournisseur.Pays IN (
    'France','Allemagne','Italie','Espagne','Belgique',
    'Pays-Bas','Portugal','Suède','Pologne','Autriche')
GROUP BY Fournisseur.Societe
ORDER BY CA_Total DESC;

Résultat (extrait) :

FournisseurCA_Total (€)
Aux joyeux ecclésiastiques911 541,03
Forêts d'érables561 372,18
Gai pâturage349 876,44

Interprétation : Les trois fournisseurs européens présents dans la base génèrent ensemble plus de 1,8 million d'euros de CA. « Aux joyeux ecclésiastiques » est le partenaire européen le plus stratégique pour KDou.

2 CA annuel des catégories Boissons et Desserts

Objectif : Suivre l'évolution annuelle du chiffre d'affaires de ces deux catégories.

SELECT
    Year(Commande.DateCde) AS Annee,
    Categorie.NomCateg AS Categorie,
    SUM(
        DetailCommande.Quantite
        * Produit.CoutAchat
        * Categorie.CoefMarge
        * (1 - DetailCommande.Remise / 100)
    ) AS CA_Annuel
FROM (((Commande
    INNER JOIN DetailCommande ON Commande.[N° commande] = DetailCommande.[N° commande])
    INNER JOIN Produit ON DetailCommande.RefProduit = Produit.RefProd)
    INNER JOIN Categorie ON Produit.CodeCateg = Categorie.CodeCateg)
WHERE Categorie.NomCateg IN ('Desserts', 'Boissons')
GROUP BY Year(Commande.DateCde), Categorie.NomCateg
ORDER BY Year(Commande.DateCde), Categorie.NomCateg;

3 Produits carnés jamais commandés

Objectif : Identifier les produits « Viandes/Volailles » sans aucune vente.

SELECT
    Produit.NomProd AS Produit,
    Categorie.NomCateg AS Categorie
FROM Produit
    INNER JOIN Categorie ON Produit.CodeCateg = Categorie.CodeCateg
WHERE Categorie.NomCateg = 'Viandes/Volailles'
  AND Produit.RefProd NOT IN (
        SELECT DISTINCT DetailCommande.RefProduit
        FROM DetailCommande)
ORDER BY Produit.NomProd;

Résultat :

ProduitCatégorie
Pâté de lapinViandes/Volailles
Rôti de veauViandes/Volailles

Interprétation : Ces deux produits n'ont généré aucune commande. KDou devrait envisager leur suppression du catalogue ou une action promotionnelle ciblée.

4 Clients pilotes ayant autant de commandes que leurs partenaires

Objectif : Repérer les duos pilote/partenaire avec un volume de commandes identique.

SELECT C1.Contact AS Pilote, C2.Contact AS Partenaire,
    (SELECT COUNT(*) FROM Commande Co1
     WHERE Co1.CodeCli = C1.CodeCli) AS NbCommande
FROM Clientele C1 INNER JOIN Clientele C2
    ON C1.CodeCli = C2.CodeCliPart
WHERE (SELECT COUNT(*) FROM Commande Co1 WHERE Co1.CodeCli = C1.CodeCli)
    = (SELECT COUNT(*) FROM Commande Co2 WHERE Co2.CodeCli = C2.CodeCli)
ORDER BY C1.Contact;

Résultat :

PilotePartenaireNbCommande
Gus KerbaIsabelle Tricote17

Interprétation : Un seul couple présente une égalité parfaite à 17 commandes chacun, ce qui peut indiquer une relation commerciale bien équilibrée au sein de ce réseau.

5 Top 5 des produits les plus commandés (en quantité)

Objectif : Identifier les produits générant le plus grand volume de ventes.

SELECT TOP 5
    Produit.NomProd AS Produit,
    SUM(DetailCommande.Quantite) AS QuantiteTotale
FROM DetailCommande
    INNER JOIN Produit ON DetailCommande.RefProduit = Produit.RefProd
GROUP BY Produit.NomProd
ORDER BY QuantiteTotale DESC;

Résultat (exemple) :

ProduitQuantité totale
Ravioli Angelo1 263
Camembert Pierrot1 057
Tarte au sucre981
Mozzarella di Giovanni924
Gnocchi di nonna Alice899

Interprétation : Les produits italiens dominent le top 5. KDou pourrait renforcer ses stocks sur ces références et négocier de meilleures conditions avec leurs fournisseurs.

6 Nombre de clients par pays, triés par ordre décroissant

SELECT

3. Indicateur personnel

Taux de remise moyen par catégorie de produit

Problématique : Quelle est la remise moyenne accordée aux clients pour chaque catégorie de produits ? Cet indicateur permet à KDou de vérifier que sa politique de remise est cohérente et ne nuit pas à sa marge par catégorie. 

SELECT
    Categorie.NomCateg AS Categorie,
    AVG(DetailCommande.Remise) AS RemiseMoyenne_Pct
FROM ((DetailCommande
    INNER JOIN Produit ON DetailCommande.RefProduit = Produit.RefProd)
    INNER JOIN Categorie ON Produit.CodeCateg = Categorie.CodeCateg)
GROUP BY Categorie.NomCateg
ORDER BY RemiseMoyenne_Pct DESC;

Résultat (exemple) :

CatégorieRemise moyenne (%)
Boissons6,12
Desserts5,78
Viandes/Volailles4,23
Produits laitiers3,95
Épicerie fine3,40

Interprétation : Les Boissons et Desserts bénéficient des remises les plus importantes. Or, ce sont aussi les catégories avec le CA le plus élevé (cf. Mission 2). KDou devrait s'assurer que ces remises ne réduisent pas trop les marges sur ces catégories stratégiques. Une révision de la grille tarifaire pour les Boissons pourrait améliorer la rentabilité globale.
